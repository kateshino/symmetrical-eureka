But if you were to use it, here's a guide:

python3 markovchain.py yourtextfile.txt - Generates one sentence by itself using a text file.
python3 markovchaingenerate.py yourtextfile.txt newjson.json - Creates a python dictionary from the text file acting as the markov chain, exports it to json.
python3 markovchainread.py yourjson.json - Takes json from earlier and generates one sentence with it.
